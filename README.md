# \# expense-tracker

Tracking expenses



\## Features:

1. Add custom expenses to a list.
2. Edit the expenses in the list.
3. Delete expenses from the list.
4. Automatically calculate total expenses.
5. Local storage saves expenses between visits.



\## Technologies Used:

1. HTML
2. CSS
3. JavaScript
4. Bootstrap
5. Browser Local Storage
